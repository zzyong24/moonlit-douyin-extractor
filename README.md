# 月明·抖音作品与评论萃取

从自己的抖音创作者中心读取作品指标和评论，按作品保存到本地，供复盘和选题使用。

## 你会得到什么

- 作品元数据和采集时间
- 播放、点赞、评论、分享、收藏等指标
- 评论记录、汇总索引及不完整原因

## 试着这样说

```text
用 moonlit-douyin-extractor。采集我这个抖音账号的作品指标和评论，按作品保存。先检查登录，遇到过期再引导我扫码。
```

## 安装与首次使用

将本仓库的完整目录交给支持本地 Skill 的 Agent 安装，保留 `SKILL.md` 与随附资源。已有同名版本时先检查差异；使用版本锁的工作区沿用自身升级机制。

让 Agent 安装：

```text
请安装这个 Skill：https://github.com/zzyong24/moonlit-douyin-extractor
```

也可通过 Skills CLI 安装：

```bash
npx skills add zzyong24/moonlit-douyin-extractor
```

## 配置与依赖

需要 Node.js 22+、已初始化的 ego-browser、Playwright 与 Chromium，以及用户自己的抖音账号登录。登录态由使用方本机目录保存，仓库不包含账号会话。

## 数据与使用边界

网络请求访问抖音创作者服务，读取结果保存到使用方作品目录。只处理用户自己的账号，不承担对标博主采集；评论可能不完整，应保留截断原因。独立安装后的登录与采集尚未重测。

执行流程与资源导航见 [SKILL.md](SKILL.md)。安装检查不代表真实业务验收；需要外部服务、账号登录或付费生成的步骤，应在使用者自己的环境中验证。
